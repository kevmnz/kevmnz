## 📚 Proyecto Destacado
### [ONG Analytics System](https://github.com/kevmnz/ong-analytics-system)
Pipeline de datos completo para la gestión contable de una organización sin fines de lucro.
**El problema**: Datos contables en Excel desorganizados, sin normalización ni trazabilidad.
**La solución**:
- Limpieza y normalización de datos provenientes de múltiples hojas de cálculo
- Dashboard interactivo en Looker Studio con KPIs, filtros y análisis de tendencias
- Base de datos PostgreSQL con 7 tablas normalizadas, sistema de auditoría y carga incremental
- Pipeline ETL con Python y Pandas para la ingesta automatizada de datos
**Tecnologías**: PostgreSQL · Python · Pandas · Looker Studio · Google Sheets
